The Uno-like ET-game:

Requirements:
- VRCSDK should be imported first as the card game depends on content included in VRCSDK

Features:
- Oculus Quest ready
- Colour scheme that works for partially colour blind people
- Guide textures to explain the symbolism on the cards
- Alternate texture with line under 6 and 9 (apply the texture to the shaders if you want to use them)
- Vector template for custom textures

To use:
- Everything must be placed under either a table gameobject or an empty gameobject. Place one Deck prefab that every other prefab on the same table must link to. Place any amount of Draw Card prefabs and Return card prefabs but at least one of each.
